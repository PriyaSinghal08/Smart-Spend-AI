# Smart Spend-AI
Smart Spend-AI is a beginner-friendly AI/ML project that predicts the category of an expense from its description.

## Objective
The project uses Machine Learning to automatically classify expenses into categories such as Food,Travel,Shopping,Bills,Education,and,Entertainment.

## Features
- Expense category prediction
- Text-based Machine Learning
- Simple Streamlit web interface
- Multiple expense testing
- Easy-to-use interface

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression

## How it Works
1. Expense data is loaded from a CSV file.
2. Text descriptions are converted into numerical features using TF-IDF.
3. A Logistic Regression model is trained on the data.
4. The user enters a new expense description.
5. The model predicts the expense category.
